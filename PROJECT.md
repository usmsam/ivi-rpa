# ivi-rpa

## Суть
Панель управления RPA/браузерной автоматизацией: пользователь создаёт сценарии автоматизации, управляет антидетект-профилями браузера, прокси и сайтами, а встроенный фрейм показывает/контролирует целевую страницу. Инструмент для роботизации рутинных действий в вебе.

## Стек
- **Create React App** (`react-scripts`), JavaScript, SCSS-модули.
- **Стейт:** Redux Toolkit.
- **Данные/формы:** `axios`, `react-select`, `react-datepicker`, `react-time-picker`, `react-icons`, `classnames`.

## Архитектура
Feature-Sliced Design:
- `src/shared/api` — axios-инстанс + маршруты (`profiles`, `proxies`, `scenarios`, `tags`) и `file` (загрузка).
- `src/shared/store/slices` — `profiles`, `scenarios`, `options`, `frameUrl` (URL встроенного фрейма), `counter`.
- `src/views/*` — разделы: `Scenarios`, `Profiles`, `Proxies`, `Sites`, `Settings`.
- `src/components/*`, `src/App.js`.

## Фичи
- **Сценарии:** создание и ведение сценариев автоматизации (с расписанием — datepicker/time-picker).
- **Профили:** антидетект-профили браузера.
- **Прокси:** управление списком прокси.
- **Сайты:** целевые ресурсы автоматизации.
- **Встроенный фрейм:** просмотр/контроль целевой страницы через `frameUrl` в сторе.
- **Теги:** маркировка сущностей.

## Сложные места
- **Управляемый встроенный фрейм.** URL целевой страницы хранится в сторе (`frameUrl`) и управляет встроенным просмотром — связка панели управления и исполняемой автоматизации.
- **Связки «профиль ↔ прокси ↔ сценарий ↔ сайт».** Доменная модель автоматизации разнесена по API-маршрутам и слайсам.
- **Планирование сценариев.** Выбор дат/времени (datepicker/time-picker) для запуска по расписанию.
- **FSD на CRA.** Чистые границы `shared`/`views` в проекте на react-scripts.

## Кейсы
- **«Панель RPA: сценарии, профили, прокси».** Как смоделировать браузерную автоматизацию и связать её сущности.
- **«Управляемый фрейм целевой страницы».** URL во store как мост между UI и исполнением.
- **Статус: до ИИ.**
